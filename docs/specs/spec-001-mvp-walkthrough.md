- 本期目标：让领导/嘉宾点开链接，3 秒内走进按 CAD 还原的劳模室，并看懂每一件成果。

## 范围

逐条按"用户动作 → 看到的结果"写：

1. **进入**：打开链接 → 加载页显示"劳模创新工作室 / 正在载入场景与成果"+ 真实进度（非假进度条）→ 资产就绪**自动**进入主场景，无二次点击。
2. **漫游**：主场景全屏渲染房间、基础设施与陈设（数据来自 `scene` 表）；默认站在入口视角。WASD/方向键移动、鼠标拖拽（触屏滑动）环视、滚轮（双指）推拉视野；墙体与主要陈设碰撞不可穿透。
3. **成果目录**（左上 252px 面板）：列出**已布放**成果（缩略图 + 名称 + 类别小字，选中项白底深蓝字）；点击条目 → 镜头 1.2s 平滑移动至该成果正前方 → 自动打开介绍浮层。
4. **场景热点**：已布放成果按顺序显示编号圆徽（01/02…，白圆 + 深蓝数字 + 双层脉冲）；hover 出现名称卡；点击打开介绍浮层。
5. **介绍浮层**（右侧 400px 玻璃抽屉）：档案编号眉标、名称、类别/年份/位置标签、图文正文；「图文介绍 / 影像资料」分段页签；影像列表可查看图片、播放视频；有功能动画的成果显&#x793A;**「播放功能演示」白色主按钮** → 在场景中播放该成果的预置动画，播放中可关闭，关闭后恢复漫游交互。
6. **首访引导**：底部胶囊提示"拖动画面环视 · WASD 移动 · 点击发光成果看详情"；关闭后写 localStorage，刷新不再自动出现；右上帮助按钮随时重新唤起。
7. **异常兜底**：
   - WebGL 不可用/初始化失败 → 错误页（"请使用新版 Chrome / Edge"+ 重新加载按钮），不白屏。
   - 单件成果资料缺失 → 该成果浮层显示"内容整理中"，场景不崩。
   - 资源加载失败 → 加载页可重试；已进场景后失败则 toast 提示 + 该资源降级（缺失贴图用纯色）。
8. **性能自适应**：按帧间隔动态调整渲染清晰度（内部行为，不出现任何画质档控件）；目标 1080p 下稳定 ≥ 45fps。

- [ ] 点击目录条目：镜头平滑移动到位（≤1.2s）并自动打开对应浮层。
- [ ] 点击场景热点：打开对应浮层，内容与数据库一致（名称/类别/正文/影像）。
- [ ] 浮层页签可切换；无影像时"影像资料"页签不渲染；成果无介绍时显示"内容整理中"。
- [ ] 有 `demo_url` 的成果显示"播放功能演示"，点击能播放并完整结束；无 `demo_url` 的成果不显示该按钮（不是禁用态）。
- [ ] 关闭浮层/动画结束后，漫游与热点交互恢复正常。

- [ ] 浏览器控制台无报错；不阻塞渲染的告警需逐条说明。
- [ ] 替换 `scene.model_url` 为新场景资产，前端零代码改动可正常加载（为 spec-002 交付铺路）。

## 技术约束（实现口径）

- 前端：React 18 + TypeScript + Vite + Three.js（R3F/drei）；后端：NestJS + PostgreSQL；静态与接口同域反代（见 `tech-stack.md`）。
- 坐标：米制、Y 向上；成果摆位以 `placement`（scene_id / achievement_id / position_xyz / rotation_y / scale）为准，前端不做硬编码坐标。
- 动画：glTF 内嵌 AnimationClip，AnimationMixer 播放；本期只播预置动画，不做拆装交互。
- 资产预算：首屏关键资产 ≤ 8MB（Draco + KTX2 后）；其余按需加载 + Web Worker 解码。
- 视觉：严格按 design.md v4.3 token；组件按 §8 清单（AntD 作行为层，样式覆写）。
- **手感基线（对齐 V07 既有项目的滑顺度，2026-11-20 校准）**：垂直视野 78°（滚轮 ±5° 步进，钳制 40–92）；视高 1.66m；移速 1.55m/s；拖拽灵敏度 yaw 0.0042 / pitch 0.0036 rad/px；俯仰钳制 ±1.32 rad；镜头飞到目标 ≤0.6s 内完成。
- 埋点/统计：不做。
