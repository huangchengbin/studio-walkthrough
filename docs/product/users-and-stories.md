## 一、用户角色

规则：**每多一个角色，功能复杂度上升一层**。能砍就砍，先保核心角色体验。

| 编号 | 角色 | 他是谁 | 来干什么 | 需要登录 | 能看 | 能改 | 能删 |
|---|---|---|---|---|---|---|---|
| R1 | 观众（领导/嘉宾） | 收到链接前来参观的领导与嘉宾 | 漫游劳模室、看成果介绍、看功能仿真演示 | 否——打开链接直接进（链接公开分享） | 劳模室 3D 全场景：基础设施、陈设、成果；点击成果看图文/影像介绍；部分实物成果的动画演示 | 无 | 无 |
| R2 | 管理员（布展人） | 负责布展的运营者（当前即项目 owner 本人） | 在 3D 场景内拖拽布放成果、上传/替换成果模型与资料，布好即定稿 | 是——账号密码登录进入"布放编辑模式" | R1 能看的一切 + 布放编辑模式界面 + 成果库 | 成果在场景中的位置、旋转、显隐；成果 3D 模型/贴图/介绍资料的上传与替换；布放方案保存 | 从场景移除成果（取消布放）；删除已上传的成果资产与资料 |

### 关键边界（2026-11-19 用户拍板修订）

1. **链接访问控制**（承接 overview.md 遗留待定项）：V1 链接公开分享、不加访问控制——荣誉展示类内容一般不涉密，加口令会挡住"领导转发给其他领导"的传播路径。若后续出现保密需求，再考虑访问口令（不是观众账号注册）。
2. **3D 资产进产品界面**：管理员可在产品内上传、替换成果的 3D 模型、贴图与介绍资料，不依赖开发部署流程。（原"资产走开发流程"边界已否决）
3. **管理员用账号体系**：编辑模式凭账号密码登录。（原"固定口令"方案已否决）观众端始终免登录。

### 被砍掉的角色（及原因）

- 讲解员（远程带看，多嘉宾同步漫游）→ 需要实时同步服务端和"跟随模式"，复杂度高一个量级；V1 观众自助漫游即可，若远程带看成为真实需求，V2 再议。
- 内容编辑员（只编辑成果资料、不动布放）→ 单管理员场景下没有必要分权，分权 = 账号体系，违背"砍复杂度"原则。
- 资产维护者（界面化上传 3D 模型/贴图）→ 不设独立角色：资产管理（上传/替换模型、贴图、资料）并入 R2 管理员职责，在产品内完成（见关键边界 2）；只砍"角色"，不砍"功能"。
- 注册用户/游客分层 → 无评论、无社交、无个人数据，分层没有收益。

## 二、用户故事

格式：`作为<角色>，我想<做什么>，以便<达成什么>`。
每条故事必须能追溯到某个具体界面元素，写不出界面元素的故事说明还不成熟。

### 访问路径模拟（主线走一遍，具体到界面元素）

**R1 观众（领导/嘉宾）**：打开分享链接 → 加载页（品牌名 + 进度提示，数秒内完成）→ 进入劳模室 3D 首屏：站在入口视角看到全屋概貌，屏幕下方一条操作引导（"移动键漫游 · 点击发光成果看详情"）→ 顺着高亮提示走到一件创新工装展台前 → 点击它 → 右侧滑出成果介绍面板（名称、图文介绍、"播放功能演示"按钮、影像页签）→ 点按钮播放该工装的动作动画 → 看完关闭面板 → 继续漫游下一件 → 逛完直接关页面离开。

**R2 管理员（布展人）**：打开链接 → 点右上角"管理入口" → 账号密码登录页 → 登录后进入布放编辑模式：3D 场景不变，顶部出现编辑工具条（成果库、保存、退出编辑）→ 点开左侧成果库面板，看到未布放成果清单 → 把一件新成果拖进场景目标位置 → 选中它出现位置/旋转调整手柄，调整摆放到满意 → 点"保存"，提示"已生效"→ 切回观众视角确认效果 → 退出编辑模式。

## 三、优先级定义（全项目统一口径）

| 级别 | 含义 | 第一期是否做界面 |
|---|---|---|
| P0 | 第一期必须满足，界面必须设计好 | 是 |
| P1 | 可以做，但不一定进第一期 | 视情况 |
| P2 | 第一期连界面都不做，只保留功能位置或数据字段 | 否 |
