# 视觉规范 · design

> 第 2 期产物。这份是**给 AI 读的**规范，任何界面产出都必须遵守。
> **状态：定稿（2026-11-19）——5 个分歧点全部拍板；组件/图标/动效/参考站已接入（H）**

## 1. 整体气质

- 形容词：**现代、清爽、可靠**
- 用户第一眼应该感觉到：打开一个干净、现代的数字展厅——3D 画面是主角，UI 像展厅里排版精致的说明牌，克制退后；庄重感来自留白与克制，不靠装饰色彩。
- 明确不要变成什么样：红金满堂的荣誉展板风（横幅、烫金大字、绸缎底纹）；游戏厅（霓虹渐变、表演型动效）；SaaS 后台（表格、仪表盘、密集工具栏）。

## 2. 色彩

| 用途 | 值 | 使用占比 |
|---|---|---|
| 主色（科技蓝，主操作/焦点/链接） | `#1677FF`（hover `#4096FF` / active `#0958D9`） | ≤5%（按钮、焦点、关键强调） |
| 背景 | `#F5F7FA` | ~70% |
| 卡片/浮层 | `#FFFFFF` | |
| 描边/分隔线 | `#E3E8EF` | |
| 中性色阶 | `#F5F7FA` / `#EDF1F6` / `#E3E8EF` / `#C9D1DC` / `#9AA4B2` / `#6B7280` / `#4A5261` / `#1F2329` | 基底与文字 |
| 文字 主/次/禁用 | `#1F2329` / `#6B7280` / `#C0C6CF` | |
| 功能色（仅状态反馈） | 错误 `#FF4D4F` / 成功 `#52C41A` / 警示 `#FAAD14` | 只出现在错误、成功、警示提示 |

- 模式：**浅色**（2026-11-19 拍板）。理由：领导/嘉宾场合观感亲切，科技蓝在浅底上最干净；与 Ant Design（技术栈已选）默认浅色体系天然一致。
- 色相硬规则：**装饰性色相只允许蓝系**；红/绿/黄只准以功能色身份出现在状态反馈，禁止当装饰用；出现蓝系之外的装饰色相即违规。禁止紫色、禁止 AI 味渐变横幅。玻璃拟态仅允许浮层 `backdrop-blur: 8px` 一档，卡片禁用。
- 对比度硬指标：正文对比度 ≥ 7:1，辅助文字 ≥ 4.5:1（WCAG AA）。

## 3. 字体

| 层级 | 字体族 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| 主标题 | Microsoft YaHei 微软雅黑 | 28px | 1.4 | 700 |
| 小标题 | Microsoft YaHei 微软雅黑 | 18px | 1.5 | 600 |
| 正文 | Microsoft YaHei 微软雅黑 | 14px | 1.7 | 400 |
| 辅助文字 | Microsoft YaHei 微软雅黑 | 12px | 1.5 | 400 |

- 中文字体（2026-11-19 拍板）：**微软雅黑**——Windows 系统预装、免下载，直接服务"3 秒进入"指标；全项目不再引入任何 Web 字体。
- 西文/降级 fallback：`"Segoe UI", -apple-system, "PingFang SC", "HarmonyOS Sans", sans-serif`（Mac 上自动落到苹方）。
- 数字/代码：等宽数字 `font-variant-numeric: tabular-nums`（进度、坐标、统计位对齐）。

## 4. 排版与布局

- 栅格：本产品**无网页栅格**——全屏 3D + 浮层。浮层定位规则：介绍浮层右侧固定，宽 **400px**、距屏幕右缘与下缘各 **24px**；成果库浮层左侧固定，宽 **360px**。
- 最大内容宽度：加载页内容居中 **640px**。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（px，全项目只用这 8 个数）。
- 留白原则：HUD/浮层元素距屏幕边缘 ≥ 24px 安全距离；浮层内边距 24px；禁止任何元素贴屏幕边缘 < 16px。
- 首屏骨架（UI-02）：全屏 3D 画面 → 底部居中引导条（距底 24px）→ 右上角管理入口（24px 边距、低调）→ 热点在 3D 场景内部。

## 6. 组件形状规则

| 元素 | 规则 |
|---|---|
| 圆角 | 全局统一 **8px**（2026-11-19 拍板；面板、按钮、输入框、标签一律同值） |
| 边框 | 1px `#E3E8EF`；focus 态 1px `#1677FF` + 2px 光晕 `rgba(22,119,255,.15)` |
| 阴影 | 只有两档：浮层 `0 12px 32px rgba(15,23,42,.12)`；按钮/输入框/卡片**不用阴影** |
| 按钮 | 主按钮高 40px（次级 32px），padding 0 20px；主按钮蓝底 `#1677FF` + 白字；hover `#4096FF`、active `#0958D9`、disabled 40% 不透明度、loading 转圈且禁点 |
| 输入框 | 高 40px，底 `#FFFFFF`，1px `#E3E8EF` 边框；focus 蓝边光晕；错误态红边 `#FF4D4F` + 12px 红色提示文字在框下方 4px |
| 卡片 | 底 `#FFFFFF`，内边距 16px，圆角 8px，1px 边框；分隔用 1px `#E3E8EF` 线，禁用灰底色块 |
| 标签与徽标 | 高 22px、圆角 4px、12px 字；全部用中性底 `#EDF1F6` + 深字 `#4A5261`，**不按类别分色**（2026-11-19 拍板 A） |

## 7. 设计约束（禁止清单）

- 禁止用 emoji 当图标，全项目只用一套图标库：**@ant-design/icons**（唯一图标源；尺寸只准 16/20/24 三档，颜色随文字 token，不单独着色）
- 禁止混用两套圆角体系（全局只准 8px 一套）
- 禁止出现 design.md 之外的颜色与字号（间距只用 4/8/12/16/24/32/48/64）
- 禁止每个页面用不同字体（全项目只微软雅黑一族，按层级表用）
- 动效只有一个程序化来源：**GSAP**（3D 热点脉冲、镜头过渡等任何 JS 驱动动效一律用它）；DOM 悬停/聚焦等状态过渡用 CSS transition（属基础样式，不算动效库）；UI 动效时长约束：微交互 120–180ms、面板出入 240–320ms、一律 ease-out；禁止 UI 上出现旋转、弹跳、视差等表演型动效（3D 场景内部镜头运动属于内容，不受此限）
- 禁止 UI 面板上放图片背景、渐变横幅、大面积铺蓝（蓝色占比 >20% 即违规）
- 禁止小于 12px 的文字
- 浅色界面禁止大面积纯黑 `#000` 背景（最深只用文字级 `#1F2329`）

| 类别 | 来源链接 | 用途 |
|---|---|---|
| UI 组件库 | Ant Design 5 · ant.design | 表单、抽屉、上传、按钮全量；浅色蓝系与 §2 天然一致（技术栈已选） |
| 图标库 | @ant-design/icons | 唯一图标源，与 AntD 同家族零冲突 |
| 动效库 | GSAP · gsap.com | 唯一程序化动效源（3D 热点脉冲、镜头过渡） |
| 参考站 A | Apple 产品页 · apple.com.cn | 借布局逻辑：全屏画面主导、UI 退后 |
| 参考站 B | 全景故宫 · pano.dpm.org.cn | 借展陈手法：展签式渐进披露、一次性引导 |

### 素材能力说明（逐个）

- **Ant Design 5**：提供 Form/Input/Drawer/Upload/Progress/Button/Modal 等全部所需组件，浅色 + 蓝主色是默认体系，定制成本最低。
- **@ant-design/icons**：AntD 配套图标，覆盖本项目所需（播放、上传、保存、关闭、设置等），无需引入第二套。
- **GSAP**：处理 3D 场景内的热点脉冲与镜头过渡（Three.js 无内置补间编排），成熟稳定、免费核心够用。
- **参考站 A（Apple）**：学"产品本体即页面"的章法——大画面、少控件、单一主操作。
- **参考站 B（全景故宫）**：学线上展馆的观展节奏——展签式信息分级、首访引导只出现一次。

### 3 条可复用规则（借方法不抄像素）

1. **画面主导**：任何屏 UI 元素总面积 ≤ 画面 15%，主操作只有一个，其余全部降级（来源：参考站 A）。
2. **展签式渐进披露**：热点先给"名称 + 一句话"，细节才进浮层；信息永远分两级给（来源：参考站 B）。
3. **引导一次性 + 可重看**：首访提示一次，之后不弹窗；引导入口常驻但低调（来源：参考站 B）。
