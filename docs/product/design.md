# 视觉规范 · design

> 第 2 期产物。这份是**给 AI 读的**规范，任何界面产出都必须遵守。
> **状态：初版已填（提示词 G，2026-11-19）——文末 5 个分歧点待人工拍板后修订定稿；图标库/动效库/组件库待 H 填**

## 1. 整体气质

- 形容词：**庄重、精细、安静**
- 用户第一眼应该感觉到：像推开一间被精心布置的荣誉展室，而不是"打开了一个软件"——3D 画面是绝对主角，UI 面板像展室里的说明牌，安静退后。
- 明确不要变成什么样：游戏厅（霓虹渐变、表演型动效满天飞）；SaaS 后台（表格、仪表盘、密集工具栏）；红头文件政务风（边框套边框、大红标题、艺术字）。

## 2. 色彩

| 用途 | 值 | 使用占比 |
|---|---|---|
| 主色（界面基底） | `#0E1116` 背景 / `#1A1F27` 卡片 / `#2A3140` 描边 | ~70% |
| 强调色（荣誉金，主操作） | `#D4A64C`（hover `#E0B75F` / active `#C09240`） | ≤5% |
| 荣誉红（点缀） | `#C94F4F`（仅类别点缀与错误态） | ≤2% |
| 中性色阶 | `#0B0E13` / `#11141A` / `#1A1F27` / `#242B36` / `#2A3140` / `#4A5568` / `#8A93A3` / `#A8B0BD` / `#F2F4F8` | 基底与文字 |
| 背景 | `#0E1116` | |
| 卡片 | `#1A1F27` | |
| 文字 主/次/禁用 | `#F2F4F8` / `#A8B0BD` / `#5A6272` | |

- 模式：**深色 HUD**。理由：界面浮在光影 3D 场景上，深色面板不与画面抢注意力，领导/嘉宾在投影与普通屏幕上观看都成立。
- 禁止：全项目只允许 **3 个色相**（深中性 / 金 / 红），出现第 4 色相即违规；禁止紫色渐变与一切 AI 味渐变横幅；玻璃拟态仅允许浮层 `backdrop-blur: 8px` 一档，卡片禁用。
- 对比度硬指标：正文对比度 ≥ 7:1，辅助文字 ≥ 4.5:1（WCAG AA）。

## 3. 字体

| 层级 | 字体族 | 字号 | 行高 | 字重 |
|---|---|---|---|---|
| 主标题 | Noto Serif SC（思源宋体） | 28px | 1.4 | 600 |
| 小标题 | Noto Sans SC | 18px | 1.5 | 600 |
| 正文 | Noto Sans SC | 14px | 1.7 | 400 |
| 辅助文字 | Noto Sans SC | 12px | 1.5 | 400 |

- 中文字体：界面用 **思源黑体 Noto Sans SC**；主标题（加载页劳模室名称、浮层标题）用 **思源宋体 Noto Serif SC**，取仪式感。均配 `font-display: swap`，不阻塞"3 秒进入"。
- 西文 fallback：`Inter, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 数字/代码：等宽数字 `font-variant-numeric: tabular-nums`（进度、统计位对齐）。

## 4. 排版与布局

- 栅格：本产品**无网页栅格**——全屏 3D + 浮层。浮层定位规则：介绍浮层右侧固定，宽 **400px**、距屏幕右缘与下缘各 **24px**；成果库浮层左侧固定，宽 **360px**。
- 最大内容宽度：加载页内容居中 **640px**。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（px，全项目只用这 8 个数）。
- 留白原则：HUD/浮层元素距屏幕边缘 ≥ 24px 安全距离；浮层内边距 24px；禁止任何元素贴屏幕边缘 < 16px。
- 首屏骨架（UI-02）：全屏 3D 画面 → 底部居中引导条（距底 24px）→ 右上角管理入口（24px 边距、低调）→ 热点在 3D 场景内部。

## 6. 组件形状规则

| 元素 | 规则 |
|---|---|
| 圆角 | 全局统一 **8px**（面板、按钮、输入框、标签一律同值） |
| 边框 | 1px `#2A3140`；focus 态 1px `#D4A64C` + 2px 光晕 `rgba(212,166,76,.25)` |
| 阴影 | 只有两档：浮层 `0 12px 48px rgba(0,0,0,.48)`；按钮/输入框/卡片**不用阴影** |
| 按钮 | 主按钮高 40px（次级 32px），padding 0 20px；主按钮金底 `#D4A64C` + 深字 `#14100A`；hover `#E0B75F`、active `#C09240`、disabled 40% 不透明度、loading 转圈且禁点 |
| 输入框 | 高 40px，底 `#141922`，1px 边框；focus 金边光晕；错误态红边 `#C94F4F` + 12px 红色提示文字在框下方 4px |
| 卡片 | 内边距 16px，圆角 8px，1px 边框；分隔用 1px `#2A3140` 线，禁用灰底色块 |
| 标签与徽标 | 高 22px、圆角 4px、12px 字；全部用中性底（`#242B36`）+ 金字 `#D4A64C`，**不按类别分色** |

## 7. 设计约束（禁止清单）

- 禁止用 emoji 当图标，全项目只用一套图标库：**待 H 阶段选定**（唯一图标源）
- 禁止混用两套圆角体系（全局只准 8px 一套）
- 禁止出现 design.md 之外的颜色与字号（间距只用 4/8/12/16/24/32/48/64）
- 禁止每个页面用不同字体（全项目就思源宋/思源黑两族，按层级表用）
- 动效只用一套动效源：**待 H 阶段选定**；UI 动效时长约束：微交互 120–180ms、面板出入 240–320ms、一律 ease-out；禁止 UI 上出现旋转、弹跳、视差等表演型动效（3D 场景内部镜头运动属于内容，不受此限）
- 禁止 UI 面板上放图片背景、渐变横幅、大面积铺金
- 禁止小于 12px 的文字
- 深色界面禁止纯黑 `#000` 大面积背景（用 `#0E1116`）
