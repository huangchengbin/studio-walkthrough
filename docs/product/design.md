# 视觉规范 · design

> 第 2 期产物。这份是**给 AI 读的**规范，任何界面产出都必须遵守。
> **状态：v3 定稿（2026-11-20 按用户反馈回炉）——国网绿主题替换科技蓝，吸收 V07 质感手法，布局转导览型；样张见 `design-lab/full/`**

## 1. 整体气质

- 形容词：**精致、克制、有质感**
- 用户第一眼应该感觉到：一个被精心打磨过的数字展厅——画面是主角，面板像展柜上的玻璃铭牌，安静但有分量；高级感来自层次（玻璃、内高光、字距），不来自装饰。
- 明确不要变成什么样：红金满堂的荣誉展板风；游戏厅（霓虹渐变、表演型动效）；SaaS 后台（表格、仪表盘、密集工具栏）；扁平白卡堆砌（只有 1px 边框和单层阴影的"工程样板"）。

## 2. 色彩

| 用途 | 值 | 使用占比 |
|---|---|---|
| 主色（深蓝科技，深底提亮版） | `#3B82F6`（亮端 `#5C9EFF` / 按压 `#2563EB`） | ≤6% |
| 背景（蓝黑） | `#0E1B33`；加载/登录用径向 `#0B111C → #0F1B2C` | ~65% |
| 面板（深色玻璃渐变） | `linear-gradient(180deg, rgba(27,44,76,.86), rgba(14,26,48,.92))` | |
| 描边/分隔 | `rgba(255,255,255,.09)`；面板外沿 `rgba(255,255,255,.10)` | |
| 文字 主/次/禁用 | `#E9EEF6` / `#A6B3C2` / `#5C6878` | |
| 弱化字（眉标/说明） | `#77859A` | |
| 标签底/字 | `rgba(255,255,255,.07)` / `#C3D0DE` | |
| 按钮白（主操作专用） | `#FFFFFF` 底 + 深蓝字 `#12386E`（hover `#EEF4FF` / 按压 `#DCE8FB`） | ≤4% |
| 功能色（仅状态反馈） | 错误 `#FF6467` / 警示 `#FFB020` / 成功 `#52C41A` | 仅错误、未保存、成功提示 |

- 模式：**深色蓝黑科技**（2026-11-20 拍板，替代浅色；历史见拍板记录）。
- 质感 token（必须使用）：
  - `--shadow-1: 0 1px 0 rgba(255,255,255,.07) inset, 0 18px 44px -20px rgba(3,9,22,.75), 0 2px 8px rgba(3,9,22,.4)`（面板/浮层/图标钮）
  - `--shadow-2: 0 30px 90px -28px rgba(3,9,22,.9)`（模态/大浮层）
  - `--grain`：SVG feTurbulence 噪点，`mix-blend-mode: overlay`，透明度 ~70%（深底颗粒感，必须保留）
  - 场景暗角：`radial-gradient(125% 95% at 50% 42%, transparent 58%, rgba(10,20,35,.34))`
- 渐变规则：**控件级渐变允许**（主按钮 135° 蓝渐变、选中项渐变）；**大面积渐变横幅禁止**。
- 色相硬规则：装饰性色相只允许**深蓝系**；红/黄/绿功能色仅以状态提示身份出现。禁止紫色、禁止霓虹多色。玻璃用渐变仿制，禁止 backdrop-filter 叠在动画 3D 上。
- 对比度硬指标：深底上正文 ≥ 7:1，辅助文字 ≥ 4.5:1（WCAG AA）。

## 3. 字体

| 层级 | 字体族 | 字号 | 行高 | 字重 | 字距 |
|---|---|---|---|---|---|
| 主标题 | 微软雅黑 | 26–28px | 1.4 | 700 | .06em |
| 小标题 | 微软雅黑 | 18px | 1.5 | 650 | .02em |
| 正文 | 微软雅黑 | 13–14px | 1.8–1.9 | 400 | 0 |
| 辅助/说明 | 微软雅黑 | 11–12px | 1.6 | 400 | .04em |
| 眉标（eyebrow） | 微软雅黑 | 10px | 1.4 | 600 | .16em |

- 中文字体：**微软雅黑**（系统预装、零 Web 字体，服务"3 秒进入"）。
- 字距是 v3 质感的一部分：**标题与眉标必须带字距**（无字距即违规）；正文不加字距。
- 西文/降级：`"Segoe UI", -apple-system, "PingFang SC", sans-serif`。
- 数字：`font-variant-numeric: tabular-nums`。

## 4. 排版与布局（导览型）

- 布局语言：**导览型**——全屏 3D 之上浮着玻璃面板（2026-11-20 拍板）：
  - 顶栏：高 72px，左品牌标 36px + 标题/副标，右侧动作区（帮助图标钮 + 管理入口）
  - 左栏：成果目录，宽 252px，距边 24px，顶 96px
  - 左下：平面定位卡，宽 248px
  - 底部：控制条居中（分段控件 + 图标钮组），上方 8px 距一条胶囊提示
- 浮层：介绍抽屉宽 400px（右 24 / 上 96 / 下 24）；成果库为 940×600 档案弹窗（圆角 16）。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64（仅这 8 个数）。
- 留白原则：浮层/面板距边 24px；面板内边距 18–24px；禁止元素贴边 <16px。
- 首屏骨架（UI-02）：全屏 3D → 顶栏 → 左目录栏 → 左下平面卡 → 底部控制条 → 胶囊提示 → 场景热点。

## 7. 设计约束（禁止清单）

- 禁止 emoji 当图标；唯一图标源 **@ant-design/icons**（16/20/24 三档，随 `currentColor`）
- 禁止三级圆角之外的任何圆角（面板 14 / 控件 9–10 / 标签 4 / 弹窗 16）
- 禁止 design.md 之外的颜色、字号、字距；间距只用 4/8/12/16/24/32/48/64
- 禁止全项目混用字体（只微软雅黑一族）
- 动效只有一个程序化来源：**GSAP**；DOM 状态过渡用 CSS（属基础样式）。时长：微交互 120–180ms、面板出入 240–320ms、一律 ease-out；允许的"表演"只有 hover 上浮 1px 与呼吸徽标；禁止旋转/弹跳/视差
- 禁止 UI 上出现大面积渐变横幅、图片背景、大面积铺绿（绿 >20% 面积）
- 禁止 <12px 正文（眉标 10px 是唯一例外）
- 禁止纯黑 `#000` 大面积背景（最深用深海军蓝 `#0E1B33`）
- 禁止 backdrop-filter 叠在 3D 动画区上（性能陷阱，玻璃用渐变仿制）

### 2026-11-20（v4.5 室内材质分层与布光）
