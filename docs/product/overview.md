# 产品定位 · overview

> 全文只允许在这一处描述产品定位。其他文档引用这里，不要复述。
> **状态：已填（2026-11-19，提示词 B 需求收敛完成）**

## 一句话描述

一款在浏览器里精细还原"劳模室"室内实景的 3D 线上展厅：领导嘉宾点开链接即可走进按真实尺寸还原的数字劳模室，漫游观看室内的创新成果、基础设施与陈设，点击成果可查看介绍与功能仿真演示。

## 给谁用

- **领导与嘉宾（观众）**：异地或不便亲临现场的参观者，现状痛点是只能看照片/视频，看不出空间关系与细节，且不能随到随展。
- **管理员（布展人）**：负责把成果在 3D 场景内布放到位的运营者，现状痛点是成果更新后线下重新布展成本高。

## 解决什么痛点

现在的替代方案是实体劳模室参观 + 照片视频资料。问题：受时间地点限制、无法随到随展、展示粒度粗、成果一更新就要重新布展。本产品让劳模室 24 小时在线，成果更新只需在数字场景里重新拖放。

## MVP 核心功能（只列 1 个最重要的）

**Web 端 3D 漫游展厅**：打开链接即进入按 CAD 图纸尺寸还原的劳模室，自由漫游到任意成果前，点击查看图文/影像介绍，部分实物成果可播放功能动画演示。

## 功能分期（提示词 B 收敛结论）

| 版本 | 内容 | 状态 |
|---|---|---|
| V1（MVP） | 3D 漫游展厅 + 成果点击介绍 + 部分成果动画仿真 + 管理员在 3D 场景内拖拽布放（布好即定稿） | 本期开发 |
| V2 | 成果可交互操作仿真（点选、拆装、调参数） | 后续 |
| V3 | 真实设备/系统数据联动仿真 | 后续 |

## 成功标准（可衡量）

- 领导/嘉宾无需安装任何插件或 APP，点开链接 3 秒内进入劳模室场景
- 能自由漫游到任意成果前，点击后在 5 秒内看到该成果的介绍内容
- 室内布局与房间尺寸和 CAD 图纸一致，成果外观与实景照片比对"一眼认得出"
- 管理员在 3D 场景内拖拽布放一个成果并保存，全程 ≤ 2 分钟

## 明确不做什么（这一版砍掉的）

- 不做移动端原生 APP、大屏专用客户端——只做浏览器 Web 端
- 不做 VR/AR 眼镜适配
- 不做多用户协同编辑、评论、点赞等社交功能
- 不做嘉宾侧的布放/编辑权限——布放仅管理员可用，布好即定稿
- 不做真实数据联动仿真（放 V3）
- 不做复杂的成果管理后台——起步阶段以轻量布放编辑满足需求（具体形态见后续 SPEC）

## 反向参考（不要变成什么样）

- 变成要下载插件、白屏转圈的"重"应用——领导点开就关，一票否决。
- 变成没有引导、按键一堆、要培训才会逛的软件——嘉宾的第一个动作就卡住。
- 场景塑料感强、贴图粗糙，"精细化还原"名不副实，反而损害劳模形象。

## 遗留待定

- 链接是否需要访问控制（对外公开 vs 仅内部可见）——进入 C 阶段后随用户角色设计一起定。
