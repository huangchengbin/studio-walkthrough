# 界面信息架构

> 本文件只负责：有哪些界面、每屏用户此刻最需要看到什么、主操作是什么。
> **状态：已填（E 第二步 2026-11-19；2026-11-20 按导览型布局修订）**

## 界面清单

| 编号 | 界面 | 角色 | 覆盖的 P0 故事 | 是否首页 |
|---|---|---|---|---|
| UI-01 | 加载页 | R1 | US-01 | 过渡屏（自动进入下一屏） |
| UI-02 | 3D 漫游主场景 | R1（兼 R2 入口） | US-01、US-02、US-03、US-05、US-06 | **是（首页）** |
| UI-03 | 成果介绍浮层（玻璃抽屉） | R1 | US-03、US-04 | 浮层（挂在 UI-02 上） |

| UI-06 | 成果库（档案弹窗） | R2 | US-10 | 模态浮层（挂在 UI-05 上） |

规则：
- **只做 P0 故事覆盖到的界面**，P1/P2 的界面先不设计（US-12 显隐控制、US-13 状态标记、US-14 观察点、US-15 平面定位等均不进本清单）。
- 界面数量能少就少，能合并就合并：观众 3 屏（1 过渡屏、1 浮层）、管理 3 屏（1 模态浮层）。
- **P1 探索项（样张中演示、不进 V1 开发）**：观察点列表（US-14）、平面定位卡（US-15）、底部"整体鸟瞰/自动环视"控件——`design-lab/full/` 样张已含其布局探索，开发前须补故事并排期。
- **P2 项（第一期连界面都不做）**：成果搜索/筛选（US-16）、可交互仿真（US-17，V2）、真实数据联动（US-18，V3）——只在数据模型保留位置/字段，不设计界面。

## 每屏信息层级（按界面逐段填）

### UI-01 · 加载页

- **用户此刻的任务**：等场景就绪，马上开始参观。
- **主操作（只能有一个）**：无——加载完成自动进入 UI-02，不让用户多点一下。
- **必须出现**（按重要性排序）：
  1. 劳模室名称与一句话介绍（建立第一印象）
  2. 加载进度提示（进度条或百分比，证明"没死机"）
- **可以出现但不重要**：一句参观预告（"点击发光成果可查看详情"），降低首屏学习成本。
- **明确不该出现**：登录框、菜单、管理入口、任何需要用户先做的选择。
- **空状态**：不适用（必有内容）。
- **失败/异常**：加载失败显示"重试"按钮与一句人话报错（不暴露错误码堆栈）。

### UI-02 · 3D 漫游主场景（首页，导览型布局）

- **用户此刻的任务**：自由逛劳模室，并从成果目录里找到感兴趣的成果。
- **主操作（只能有一个）**：点击成果热点（打开 UI-03）。
- **必须出现**（按重要性排序）：
  1. 全屏 3D 劳模室场景（按 CAD 尺寸还原）
  2. 成果热点高亮（可点击的发光/描边提示）
  3. 左侧成果目录栏（252px 玻璃面板，US-06：条目含类别小字，当前项高亮）
  4. 底部居中引导胶囊：首访展示"拖动画面环视 · WASD 移动 · 点击发光成果看详情"，可关闭
  5. 右上角帮助图标钮（引导重看入口）与低调的"管理入口"
- **可以出现但不重要**：底部控制条（分段控件与视角按钮——P1 探索，V1 可先隐藏）
- **明确不该出现**：观众侧编辑/管理控件、密集大段文字、登录提示、与参观无关的元素
- **空状态**：不适用（场景本体即内容）
- **失败/异常**：WebGL 不可用或性能不足时提示"请使用新版 Chrome / Edge 浏览器"；帧率过低自动降画质

### UI-03 · 成果介绍浮层（玻璃抽屉）

- **用户此刻的任务**：了解眼前这件成果。
- **主操作（只能有一个）**：播放功能演示（带动画的成果）；无动画成果主操作退为"阅读图文"。
- **必须出现**（按重要性排序）：
  1. 成果名称（主标题层级）
  2. 图文正文与"图文 / 影像"分段页签
  3. "播放功能演示"按钮（仅有功能动画的成果出现）
  4. 关闭按钮
- **可以出现但不重要**：档案编号眉标、类别/年份/布展位置标签
- **明确不该出现**：编辑、删除、布放入口；其他成果推荐列表
- **空状态**：成果暂无介绍时显示名称 + "内容整理中"
- **失败/异常**：动画/影像加载失败在该区域内给"重试"，不影响浮层其他内容

### UI-04 · 管理登录页

- **用户此刻的任务**：安全进入布放编辑模式。
- **主操作（只能有一个）**：登录。
- **必须出现**（按重要性排序）：
  1. 账号输入框
  2. 密码输入框
  3. 登录按钮
- **可以出现但不重要**：错误提示文案。
- **明确不该出现**：注册入口、找回密码（单管理员，凭据线下重置）。
- **空状态**：不适用。
- **失败/异常**：账密错误明确提示；连续失败做简单延时限制，防暴力尝试。

### UI-05 · 布放编辑模式

- **用户此刻的任务**：把成果布放到位并定稿。
- **主操作（只能有一个）**：拖拽成果布放（持续交互）；"保存"为常驻可见的次级按钮。
- **必须出现**（按重要性排序）：
  1. 与观众端一致的 3D 场景（所见即所得）
  2. 顶部编辑工具条：成果库按钮、保存、退出编辑
  3. 选中成果后的位置/旋转调整手柄
  4. 未保存改动提示；带未保存改动退出时弹确认
- **可以出现但不重要**：拖拽时的落点预览。
- **明确不该出现**：观众端引导条、成果大段介绍文案、任何统计/报表。
- **空状态**：场景内无成果时提示"从左侧成果库拖入成果"。
- **失败/异常**：保存失败必须提示，且绝不丢失已布放的改动。

### UI-06 · 成果库（档案弹窗，编辑模式内）

- **用户此刻的任务**：浏览成果档案、管理资产，并把成果放进场景。
- **主操作（只能有一个）**：放入场景；上传/替换表单的主操作为提交。
- **必须出现**（按重要性排序）：
  1. 成果列表（缩略图 + 名称 + 类别与文件规格）
  2. 右侧成果预览与简介（选中项的图文档案）
  3. 「上传新成果」「替换模型 / 资料」入口（3D 模型 .glb/.gltf、贴图、图文资料）
  4. 「放入场景」主按钮与关闭按钮
- **可以出现但不重要**：档案编号眉标、已布放数量小字
- **明确不该出现**：布放状态标记（US-13，P1）；无确认弹窗的删除
- **空状态**：库中无成果时引导"上传第一个成果"
- **失败/异常**：上传失败明确报错（格式不支持/超出大小限制），已填表单内容不丢失
