## 每屏信息层级（按界面逐段填）

### UI-01 · 加载页

- **用户此刻的任务**：等场景就绪，马上开始参观。
- **主操作（只能有一个）**：无——加载完成自动进入 UI-02，不让用户多点一下。
- **必须出现**（按重要性排序）：
  1. 劳模室名称与一句话介绍（建立第一印象）
  2. 加载进度提示（进度条或百分比，证明"没死机"）
- **可以出现但不重要**：一句参观预告（"点击发光成果可查看详情"），降低首屏学习成本。
- **明确不该出现**：登录框、菜单、管理入口、任何需要用户先做的选择。
- **空状态**：不适用（必有内容）。
- **失败/异常**：加载失败显示"重试"按钮与一句人话报错（不暴露错误码堆栈）。

### UI-02 · 3D 漫游主场景（首页）

- **用户此刻的任务**：自由逛劳模室，找到感兴趣的成果。
- **主操作（只能有一个）**：点击成果热点（打开 UI-03）。
- **必须出现**（按重要性排序）：
  1. 全屏 3D 劳模室场景（按 CAD 尺寸还原）
  2. 成果热点高亮（可点击的发光/描边提示）
  3. 底部操作引导条：首次访问展示"移动漫游 · 点击发光成果看详情"，可关闭（二次访问自动收起）
  4. 右上角低调的"管理入口"小按钮（服务 R2 进 UI-04，视觉上不抢戏）
- **可以出现但不重要**：引导条收起后的再次展开按钮。
- **明确不该出现**：观众侧的任何编辑/管理控件、密集大段文字、登录提示、与参观无关的元素。
- **空状态**：不适用（场景本体即内容）。
- **失败/异常**：WebGL 不可用或性能不足时提示"请使用新版 Chrome / Edge 浏览器"；帧率过低自动降画质（技术层处理，不打扰用户）。

### UI-03 · 成果介绍浮层

- **用户此刻的任务**：了解眼前这件成果。
- **主操作（只能有一个）**：播放功能演示（带动画的成果）；无动画成果主操作退为"阅读图文"。
- **必须出现**（按重要性排序）：
  1. 成果名称
  2. 图文介绍
  3. "播放功能演示"按钮（仅有功能动画的成果出现）
  4. 影像页签（有影像资料时）
  5. 关闭按钮
- **可以出现但不重要**：成果类别小标签。
- **明确不该出现**：编辑、删除、布放入口（观众只读）；其他成果推荐列表（防止注意力跳失）。
- **空状态**：成果暂无介绍时显示成果名称 + "内容整理中"。
- **失败/异常**：动画/影像加载失败在该区域内给"重试"，不影响浮层其他内容。

### UI-04 · 管理登录页

- **用户此刻的任务**：安全进入布放编辑模式。
- **主操作（只能有一个）**：登录。
- **必须出现**（按重要性排序）：
  1. 账号输入框
  2. 密码输入框
  3. 登录按钮
- **可以出现但不重要**：错误提示文案。
- **明确不该出现**：注册入口、找回密码（单管理员，凭据线下重置）。
- **空状态**：不适用。
- **失败/异常**：账密错误明确提示；连续失败做简单延时限制，防暴力尝试。

### UI-05 · 布放编辑模式

- **用户此刻的任务**：把成果布放到位并定稿。
- **主操作（只能有一个）**：拖拽成果布放（持续交互）；"保存"为常驻可见的次级按钮。
- **必须出现**（按重要性排序）：
  1. 与观众端一致的 3D 场景（所见即所得）
  2. 顶部编辑工具条：成果库按钮、保存、退出编辑
  3. 选中成果后的位置/旋转调整手柄
  4. 未保存改动提示；带未保存改动退出时弹确认
- **可以出现但不重要**：拖拽时的落点预览。
- **明确不该出现**：观众端引导条、成果大段介绍文案、任何统计/报表。
- **空状态**：场景内无成果时提示"从左侧成果库拖入成果"。
- **失败/异常**：保存失败必须提示，且绝不丢失已布放的改动。

### UI-06 · 成果库浮层（编辑模式内）

- **用户此刻的任务**：管理成果资产，并把成果放进场景。
- **主操作（只能有一个）**：从清单拖成果入场景；"上传成果"表单的主操作为提交上传。
- **必须出现**（按重要性排序）：
  1. 成果清单（名称 + 缩略图）
  2. 上传新成果入口与表单：3D 模型文件、贴图、图文介绍资料
  3. 关闭按钮
- **可以出现但不重要**：上传进度条。
- **明确不该出现**：布放状态标记（US-13，P1）；无确认弹窗的删除。
- **空状态**：库中无成果时引导"上传第一个成果"。
- **失败/异常**：上传失败明确报错（格式不支持/超出大小限制），已填表单内容不丢失。
